# Project Memory

Working plan, decisions and progress for the personal tech blog. Revisit this folder before making structural changes.

## Goal
A simple personal tech blog with a modern, techy feel:
- posts written in markdown
- about me page
- search across posts
- light/dark theme, dark by default
- works well on mobile
- hosted on Cloudflare Pages
